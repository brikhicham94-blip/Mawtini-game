# موطني – نموذج تيارت 1956

نموذج أولي ثلاثي الأبعاد مبني بمحرك Godot 4.3.

## التشغيل على الكمبيوتر
افتح المشروع في Godot 4.3 أو أحدث وشغّل المشهد الرئيسي.

## بناء Android
يحتوي المستودع على إعداد تصدير Android وسير عمل GitHub Actions لبناء APK عند كل دفع إلى main أو يدوياً من تبويب Actions.

## تحكم الكمبيوتر
- WASD أو الأسهم: الحركة
- Shift: الجري
- الفأرة: تدوير الكاميرا

## ملاحظات
